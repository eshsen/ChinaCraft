==================================================
2) chinacraft-app/ (Next.js приложение)
==================================================

Служебные папки:
- .next/
  Скомпилированные артефакты Next.js (генерируются автоматически).
- node_modules/
  Установленные npm-зависимости (внешние пакеты).
- public/
  Статические ассеты frontend.

Кодовые папки:
- app/
  Основной код приложения (страницы, компоненты, API-роуты, типы).

Конфигурационные/документные файлы:
- .gitignore
  Правила исключения файлов из git.
- AGENTS.md
  Локальные инструкции для агента/автоматизации.
- CLAUDE.md
  Дополнительная короткая заметка конфигурации.
- Dockerfile
  Сборка/запуск frontend-контейнера.
- eslint.config.mjs
  Настройки ESLint.
- next-env.d.ts
  Автогенерируемые типы Next.js для TypeScript.
- next.config.ts
  Конфигурация Next.js.
- package-lock.json
  Lock-файл npm-зависимостей.
- package.json
  Скрипты, зависимости и мета-информация frontend.
- postcss.config.mjs
  Конфиг PostCSS/Tailwind пайплайна.
- README.md
  Описание frontend-части.
- tsconfig.json
  Конфигурация TypeScript.

2.1) chinacraft-app/app/
- api/
  API-роуты Next.js (BFF-прокси и legacy-поиск).
- components/
  React-компоненты интерфейса.
- types/
  TypeScript-типы запросов/ответов поиска.
- favicon.ico
  Иконка сайта.
- globals.css
  Глобальные стили приложения.
- layout.tsx
  Корневой layout (обертка страниц, метаданные).
- page.tsx
  Главная страница: компоновка DrawingPad + SearchSidebar + ResultGrid.

2.2) chinacraft-app/app/api/
- hanzi/
  Старый endpoint поиска по JSON-словарю.
- similar/
  Legacy endpoint-прокси к внешнему сервису похожести, если он запущен отдельно.

2.3) chinacraft-app/app/api/hanzi/
- route.ts
  GET endpoint `/api/hanzi`; ищет по символу/пиньинь в `SQL/hanzi_with_translations.json`.

2.4) chinacraft-app/app/api/similar/
- route.ts
  POST endpoint `/api/similar`; маршрутизирует text/image запросы во внешний сервис похожести,
  передает фильтры top_k/HSK/strokes.

2.5) chinacraft-app/app/components/
- DrawingPad.tsx
  Канвас для рисования, инструменты кисть/ластик, очистка, экспорт в image dataURL,
  загрузка пользовательского изображения.
- ResultGrid.tsx
  Компонент выдачи top-K похожих иероглифов: score, pinyin, HSK, strokes, перевод.
- SearchSidebar.tsx
  Строка поиска, история, фильтры (`topK`, HSK, мин/макс штрихов), кнопка запуска.

2.6) chinacraft-app/app/types/
- search.ts
  Типы `SearchFilters`, `SearchCandidate`, `SearchResponse` для UI/API.


==================================================
3) SQL/ (данные и скрипты словаря/БД)
==================================================

Папка:
- hsk_словарь/   (в консоли имя может отображаться искаженно кодировкой)
  Исходные/промежуточные HSK-словари и JSON-файлы.

Файлы:
- 1.py
  Объединение JSON-данных (переводы + HSK), пересоздание SQLite БД и валидация.
- create_database.py
  Скрипт создания/заполнения базы иероглифов.
- fixed_hsk_files.py
  Исправления/нормализация HSK-файлов.
- hanzi_database.db
  SQLite база данных с иероглифами и метаданными.
- hanzi_with_translations.json
  Основной большой JSON словаря (char, pinyin, strokes, translation, hsk и т.п.).
- hsk1_unique.txt
- hsk2_unique.txt
- hsk3_unique.txt
- hsk4_unique.txt
- hsk5_unique.txt
- hsk6_unique.txt
  Уникальные наборы иероглифов по уровням HSK.
- hsk_level.py
  Скрипт обработки/назначения уровней HSK.
- test.py
  Тестовые проверки/утилиты обработки данных.
- test_db.py
  Проверки состояния и содержимого базы данных.
- translate_dataset.py
  Скрипт подготовки/добавления переводов в датасет.

3.1) SQL/hsk_словарь/
- hanzi.json
  JSON со списками/атрибутами иероглифов.
- hanzi_complete.json
  Расширенный/объединенный вариант словаря.
- hanzi_with_translations.json
  Версия словаря с переводами.
- hsk1.txt
- hsk2.txt
- hsk3.txt
- hsk4.txt
- hsk5.txt
- hsk6.txt
  Списки иероглифов по HSK-уровням.
- kk.json
  Дополнительный служебный JSON-файл обработки.
